KOUSHIK U S — PORTFOLIO WEBSITE

FILES
- index.html : website content and sections
- style.css  : dark theme, layout, colors and responsive design
- script.js  : mobile navigation and current year

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted koushik-portfolio folder in Visual Studio Code.
3. Install the "Live Server" extension in VS Code.
4. Right-click index.html and choose "Open with Live Server".

BEFORE PUBLISHING
1. In index.html, replace YOUR_EMAIL@example.com with your real email.
2. Replace YOUR_GITHUB in the GitHub link with your GitHub username.
3. Replace YOUR_LINKEDIN with your LinkedIn profile path.
4. Verify your CGPA and college details.
5. Add a real resume PDF only after you have prepared it. This starter project does not include a resume file.
6. Update project technologies and description so they exactly match your implementation.

PUBLISHING WITH GITHUB PAGES
1. Create a GitHub repository named koushik-portfolio.
2. Upload index.html, style.css, script.js and README.txt to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish the website. Your URL will appear in Settings > Pages.

Note: Google Fonts requires an internet connection. The website itself is static and does not need a backend.
